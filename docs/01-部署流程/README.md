## 推荐路径

```
第一次部署（有 PC）
  01-PC端部署 → 用演示模式验证界面 → 05 拿整合包并抓包 → 接真服务器 → 验证四道关
      ↓
想 24h 挂机不占 PC
  02-Termux安卓部署（首次用 zip 传包）→ restart.sh 三条判据全绿
      ↓
之后每次改代码
  03-PC到手机同步更新（PC make_deploy.py --serve + 手机 update.sh）
      ↓
要给别的设备/朋友看
  04-网络与远程访问（Tailscale 优先；公网必须 token；只读优先）
```

## 每一步的"算通过"

| 步骤 | 通过标准 |
|---|---|
| PC 部署 | 控制台能开、bot 在线、`move_to` 后坐标真的变了 |
| 手机部署 | `restart.sh` 输出 bot1/bot2 握手成功 + 控制台 HTTP 200 |
| 同步更新 | 手机 `update.sh` 跑完自动重启，日志无 `problem inflating chunk` |
| 远程访问 | 另一台设备能开到控制台；只读模式下危险动作被拒 |
| 抓包 | `doctor.py` 显示通道表 PASS；日志有 `协商成功` |
| 本地存档 | `127.0.0.1:<LAN端口>` 能进，控制台显示在线 |
