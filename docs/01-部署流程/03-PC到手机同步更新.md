# 03 · PC → 手机同步更新

> 工程纪律：**真源在 PC，手机只跑打包产物。**
> 手机上直接改 `~/termux_deploy/` 的东西，下次 `update.sh` 就被覆盖 —— 不要在那改。

---

## 1. 真源分工

| 内容 | 真源位置 |
|---|---|
| 控制台前后端 | `src/console/`（`console.py` `index.html` `brain.py` `adapters.py` `providers.py` `scenarios.py`） |
| 协议客户端 + 抓包 + 补丁 | `src/bot/`（`forge-live.mjs` `capture/` `channel-specs.json` `patches/`） |
| 手机部署脚本 | `src/deploy/`（`*.sh`） |
| 打包产物（**不手改**） | `src/deploy/termux_deploy/`（由脚本生成） |

---

## 2. 一条链路

```
PC：python src/deploy/make_deploy.py --serve
      ├─ 探测本机 LAN IP（--ip auto）
      ├─ 写 pc_ip.txt / pc_port.txt（用 \n，不是 \r\n）
      ├─ 同步 console + bot 源文件 → termux_deploy/
      ├─ 打包 termux_deploy.zip，打印大小与 md5
      └─ 起 http.server 供下载（端口被占自动顺延）
                    │
                    ▼
手机：sh ~/termux_deploy/update.sh
      ├─ 从 pc_ip.txt 读地址（可被 PC_IP/PC_PORT 环境变量覆盖）
      ├─ curl 下载 → unzip 到 $HOME
      ├─ setup.sh（资源自检 + 打补丁 + 自启）
      └─ restart.sh（杀干净 + 启动 + 握手自检）
```

`update.sh` 会把换行/空格从 `pc_ip.txt`、`pc_port.txt` 里剔掉 —— 否则 Windows 的 `\r\n`
会让 `PC_PORT` 变成 `"8000\r"`，curl 直接报 `Port number invalid`。

---

## 3. 什么时候需要做什么

| 改动内容 | PC | 手机 |
|---|---|---|
| `index.html` / `console.py` / `brain.py` / `scenarios.py` | `make_deploy.py --serve` | `update.sh` |
| `forge-live.mjs` / `capture/` / `patches/` | 同上 | 同上 |
| **`package.json`（动了依赖）** | 同上 | 先 `cd ~/termux_deploy && npm install`，**再** `update.sh` |
| 只改 Termux 脚本（`*.sh`） | 同上 | 同上 |
| 换服务器 / 换账号 | 改 `config/bots.json` 与启动脚本 | `update.sh` 后重启 |

`npm install` 之后必须重新 `node apply-patches.mjs`（`setup.sh` 会自动做），
因为安装会还原 `node_modules`。

---

## 4. 命令速查

```bash
# PC：只打包
python src/deploy/make_deploy.py

# PC：打包 + 起下载服务（前台常驻，Ctrl-C 停）
python src/deploy/make_deploy.py --serve

# PC：指定 IP/端口（比如手机连 PC 热点）
python src/deploy/make_deploy.py --serve --ip 192.168.137.1 --port 8001
```

```sh
# 手机：一条更新
sh ~/termux_deploy/update.sh

# 手机：改地址（PC 换了网段）
PC_IP=192.168.1.50 PC_PORT=8000 sh ~/termux_deploy/update.sh

# 手机：只重启不更新
sh ~/termux_deploy/restart.sh
```

## 5. 故障对照

| 现象 | 根因 | 处理 |
|---|---|---|
| `WinError 10049 地址无效` | DHCP 把 PC 换了网段，旧 IP 失效 | 用 `--ip auto`，别写死 |
| `WinError 10048 每个套接字地址只允许使用一次` | **不是地址失效**，是端口已被上次的 `http.server` 占着 | `netstat -ano \| findstr :8000` 找 PID → `taskkill /PID <PID> /F`；脚本会自动顺延到 8001… |
| 手机下载失败 | PC 侧 `--serve` 没在跑，或 IP 不对 | 先确认 PC 前台在打印下载地址 |
| `setup.sh` 没打补丁 | 在 `~/termux_deploy` 里 curl，包装成了 `~/termux_deploy/termux_deploy.zip`，`cd ~` 解压的还是旧包 | 命令一律绝对路径；看 `setup.sh` 打印的源目录/目标目录 |
| 手机里出现两层 `termux_deploy/` | ZArchiver 二次解压 | `cd ~/termux_deploy && mv termux_deploy/* . && rmdir termux_deploy` |

> 旧脚本曾用 `bind()-close()` 预检端口，再交给 `http.server` 二次 bind —— 这在"端口被占"时
> 会误报成"地址失效"。现已删除预检，改为直接起服务、失败就报占用 PID 并顺延。见坑 K15。
