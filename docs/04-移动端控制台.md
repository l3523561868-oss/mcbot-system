# 04 · 移动端控制台：构建方案与实现

> 手机端有三种形态，**别搞混**：
> ① 手机只当遥控器（后端在 PC）；② 手机既当服务器又当遥控器（后端在 Termux）；③ 装一个 APK 外壳。
> 本文把三条路都写清楚，并说明为什么"exe 转 apk"这条路不存在。

---

## 1. 三种形态对比

| | ① 遥控器 | ② 自洽（零电脑） | ③ APK 外壳 |
|---|---|---|---|
| 后端在哪 | PC | **同一部手机 Termux** | 取决于壳里填的 URL（PC 或手机） |
| 前端形态 | 手机浏览器 / 加桌面 | 手机浏览器 | 原生 App 图标 |
| 要 PC 吗 | 要（后端） | **不要** | 看情况 |
| 安装成本 | 零 | 装 Termux + 传包 | 编译 APK 或用在线工具 |
| 适用 | 偶尔看/操作 | 24h 托管 | 想要"像 App"的体验 |

三者的前端是**同一个 `index.html`** —— 没有第二套 UI 要维护。

---

## 2. 为什么 exe 不能变 APK

`MC-Bot-GUI.exe` 是 Windows 桌面程序（PyInstaller + pywebview + .NET/EdgeWebView2 依赖）。
安卓运行的是 Dalvik/ART 字节码 + NDK，两者的二进制格式、系统 API、进程模型完全不同。

所谓"exe 转 apk 工具"实际做的是：**把网页套一层 WebView 壳**。所以真正的选择是：

- 想要"App 图标 + 全屏" → 用 §5 的 WebView 工程；
- 想要"在后端在手机里跑" → 用 §4 的 Termux 方案；
- 两者可以叠加（APK 指向 `127.0.0.1:8900`）。

---

## 3. 形态①：手机当遥控器

### 3.1 后端必须监听 `0.0.0.0`

```bash
python src/console/console.py --host 0.0.0.0 --port 8900 --token <TOKEN>
```

默认只绑 `127.0.0.1`，手机连不上是**设计如此**，不是 bug。

### 3.2 手机连上来

| 方式 | 地址 | 说明 |
|---|---|---|
| Tailscale | `http://100.x.x.x:8900` | 推荐，跨网络、加密 |
| 同 WiFi | `http://192.168.1.50:8900` | 需 PC 防火墙放行 8900 |
| 公网隧道 | `https://xxx.ngrok-free.dev` | 必须开 token |

### 3.3 加到桌面（PWA 体验）

Chrome/Edge 菜单 → **添加到主屏幕**，得到一个独立图标，全屏打开，效果接近原生。
零安装、零打包，推荐先这么做，再决定要不要 APK。

## 4. 形态②：手机自洽（后端在 Termux）

这一形态的关键认知：**手机不是遥控器，它就是服务器**。

```
┌──────────────── 同一部安卓手机 ────────────────┐
│  Termux（后台）                 浏览器（前台）  │
│  ├ console.py  8900  ◀──────  http://127.0.0.1:8900
│  ├ brain.py    8902                            │
│  ├ bot1 8801 ─┐                                │
│  └ bot2 8802 ─┴──▶ MC 服务器（公网）            │
└────────────────────────────────────────────────┘
```

优点：

- 回环访问，**不需要 token**、不需要局域网、不需要公网；
- 手机拔了 WiFi 换 4G 也能跑（只要手机有网）；
- PC 关机不影响。

代价与约束：

- 安卓会回收后台进程 → `termux-wake-lock` + 电池白名单 + 插电；
- 终端行宽约 44 字符，长命令会被软折行截断 → **一律走脚本**；
- 首次 `npm install` 要下 arm 版依赖，几百 MB。

部署细节见 [01-部署流程/02-Termux安卓部署.md](01-部署流程/02-Termux安卓部署.md)。

### 4.1 手机端脚本体系（谁拉起谁）

| 脚本 | 触发者 | 行为 |
|---|---|---|
| `start_session.sh` | `~/.bashrc`（开 Termux） | 起 4 服务；`trap` 在退出时全停；心跳轮询 `pgrep` 守着 |
| `start.sh` | 手动 | 24h 常开，detach 到后台 |
| `restart.sh` | 手动 | 杀干净 → 打补丁 → 起 4 服务 → 90s 握手自检 → 起看门狗 |
| `update.sh` | 手动 | 拉包 → 解压 → `setup.sh` → `restart.sh` |
| `watchdog.sh` | `restart.sh` | 每 30s 探 8900，连续 2 次失败重启 `console.py` |
| `check.sh` | 手动 | 一次输出进程/HTTP/断连/日志行数 |

三个"看起来能省但其实不能省"的设计：

1. **不能用 `wait` 守子进程**：4 个子进程全死时 `wait` 立即返回，随即触发 `EXIT` trap
   把刚启动的进程全杀。改成 `while :; do sleep 5; pgrep -f forge-live.mjs || break; done`。
2. **不能"有 forge-live 就 exit"**：安卓常留僵尸 node，命中即退出 → `console.py` 根本没起
   → 控制台打不开。改成三个服务各自独立判断。
3. **`restart.sh` 不能只 `echo` 地址**：进程崩了/端口被占照样打印。改成真 `curl` 到 200 才算通。

## 5. 形态③：WebView APK 工程

工程位置：`src/android/`，标准 Gradle 项目，可直接用 Android Studio 打开。

```
android_webview_apk/
├── settings.gradle
├── build.gradle
└── app/
    ├── build.gradle
    └── src/main/
        ├── AndroidManifest.xml
        ├── java/com/example/mcbotconsole/MainActivity.java
        └── res/
            ├── layout/activity_main.xml
            ├── values/strings.xml              ← 改 console_url
            └── xml/network_security_config.xml ← 已允许 http 明文
```

### 5.1 改地址（唯一必改项）

`app/src/main/res/values/strings.xml`：

```xml
<string name="console_url">http://192.168.1.50:8900</string>
```

- Tailscale：`http://100.x.x.x:8900`
- 同 WiFi：`http://192.168.x.x:8900`
- 公网隧道：`https://xxxx.ngrok-free.dev`

### 5.2 编译（Android Studio）

1. File → Open → 选 `src/android`；
2. 等 Gradle 同步（首次会下 SDK 依赖）；
3. 手机开 USB 调试或开模拟器 → 点 Run；
4. 分发给别人：Build → Generate Signed Bundle / APK → APK → 签名。

### 5.3 不装开发环境也能出 APK

用任意 "Website → APK" 在线工具，把控制台 URL 填进去直接下载。
最省事，非开发者首选；代价是可定制性为零。

### 5.4 两个必知配置

- `network_security_config.xml` 已放开 http 明文，否则连 `192.168.x.x` 会被系统拦；
- 走公网隧道时后端**必须**设 `CONSOLE_TOKEN`，否则 APK 里的 URL 泄露 = bot 控制权泄露。

## 6. 移动端性能优化（都是实测踩出来的）

| 问题 | 根因 | 解法 | 效果 |
|---|---|---|---|
| 首屏十几秒 | `/icons/` 对每个模组物品去外部源拉，手机拉不到，每个等 3s 超时，一次刷新几十个 | **负缓存 + 60s 熔断**：失败过的直接 404 | 0.76s → 2ms（单图标） |
| 「服务器在线」永远"读取中…" | `loadPlayers()/loadMap()` 固定取 `STATE.bots[0]`，它一重连就 `return` | 改成"取第一只在线 bot"，全离线时显式提示 | 面板可用 |
| 日志刷 `BrokenPipeError` | 不是崩溃：HTTP/1.0 每请求重开 TCP，手机端 200+ 请求/页，浏览器中途断开 | `protocol_version="HTTP/1.1"` + `disable_nagle_algorithm` + 吞掉 BrokenPipe | 请求数降一个量级 |
| 走代理时全部 404 | 代理下请求行是**绝对 URI**（`GET http://host/api/state`），原代码按相对路径解析 | `do_GET/do_POST` 统一 `urlparse(self.path).path` | 代理环境可用 |
| 动作卡住导致整页"连接中" | bot 桥单线程，30s 超时会把浏览器 6 条连接全占死 | 适配器超时降到 **8s** | 卡住也能迅速放开 |

## 7. 移动端交互适配

| 项 | 处理 |
|---|---|
| 触摸 vs 鼠标 | 背包拖拽用 Pointer Events，不用 HTML5 drag |
| 单击 / 右键语义 | 单击 → 主手；长按/双击 → 副手（替代右键） |
| 小屏布局 | 单列纵向滚动；宽屏（≥1100px）自动分栏 |
| 表格溢出 | 关键数据用卡片，不用宽表 |
| 输入 | 输入框 `enterkeyhint`，Shift+Enter 换行，避免误发送 |
| 首屏体积 | 单 HTML（约 67 KB），无外部字体/CDN |

---

## 8. 移动端选型建议

| 你的情况 | 建议 |
|---|---|
| 只想偶尔看状态 | PC 跑后端 + Tailscale + 浏览器加桌面 |
| 想 24h 挂机且不想开电脑 | 旧手机 Termux 自洽（形态②） |
| 想"点图标就用" | 形态② + APK 指向 `127.0.0.1:8900` |
| 想把控制权给朋友 | 只读模式 + 反向接入 `reporter.py`，不要裸开公网 |
